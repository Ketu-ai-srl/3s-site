# Router de reguli: ce atingi, ce citesti

| Daca atingi | Citeste |
|---|---|
| texte vizibile pe site, cifre, dovezi | `afirmatii-atribuite.md` |
| orice fisier care ar putea purta un secret | `zero-secrete-in-cod.md` |
| ceva care depinde de un serviciu extern (Coolify, GitHub, DNS) | `verifica-preconditii-externe.md` |
| o verificare, o poarta, un raport de stare | `masoara-adevarul-nu-surogatul.md` |

Regulile sunt scurte prin proiectare. Daca una creste peste o pagina, se taie.
