# Regula: zero secrete in cod

Repo-ul `3s-site` este **PUBLIC**. Ce se comite aici e vizibil oricui, pentru totdeauna,
inclusiv in istoric dupa stergere.

- Secretele traiesc doar in variabilele de mediu ale aplicatiei Coolify si in secretele GitHub.
- Nu se comit: chei API, parole, tokenuri, adrese personale, numere de telefon, date despre clienti,
  preturi de cost, materiale interne de vanzare, analiza concurentei.
- Cand un secret ajunge totusi in istoric: se roteste intai secretul, apoi se curata istoricul.
  Ordinea inversa lasa secretul valid pe internet cat dureaza curatarea.
